# Input GeoTIFF

`HerbaceousVegetation_723.tif` is the 13-band EuroSAT scene used in the executed experiment. The notebook reports a 64 × 64 raster in EPSG:32630 with bounds approximately 478520.6396, 6184931.6394, 479160.7014, 6185571.6925.

EuroSAT was introduced by Helber et al. and is based on Sentinel-2 imagery. Users must verify and comply with the original dataset and Copernicus Sentinel data terms when redistributing or reusing the raster. This repository does not relicense third-party source imagery.

The file stored here was supplied with the manuscript materials and its integrity is recorded in the repository checksum file.
