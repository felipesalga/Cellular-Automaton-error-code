# Spectral quantum resilience for wildfire-spread models

Reproducibility archive for the manuscript **“Spectral quantum resilience: surface codes for machine-learning models of wildfire spread”** by Felipe Hernán Salgado Mondaca and Ismael Soto Gómez.

## Scope

This repository contains the executed Google Colab notebook, the 13-band GeoTIFF used in the experiment, configuration and seed records, machine-readable tables recovered from the notebook outputs, and the manuscript source. The experiment compares a cellular automaton (CA), CNN, directed GNN, and Transformer, and evaluates simulated spectral protection using a rotated surface code decoded with MWPM/PyMatching.

The networks approximate stochastic cellular-automaton realizations; the study is a computational proof of concept and is not an operational wildfire validation or a demonstration of quantum image transmission.

## Repository contents

- `notebooks/Cellular_Automaton_error_code_v2_executed.ipynb`: original executed notebook with all saved outputs.
- `notebooks/Cellular_Automaton_error_code_v2_reproducible.ipynb`: release copy that first loads `data/HerbaceousVegetation_723.tif` and falls back to Colab upload.
- `data/HerbaceousVegetation_723.tif`: 13-band EuroSAT GeoTIFF used by the executed analysis.
- `results/notebook_output_tables/`: machine-readable CSV tables extracted from displayed notebook outputs.
- `results/expected_exports.txt`: complete list of CSV/NPZ files regenerated by a full notebook execution.
- `config/experiment_config.yaml`: principal experimental parameters.
- `config/random_seeds.txt`: general, QEC, neural-training, and bootstrap seeds.
- `config/software_environment.txt` and `requirements.txt`: software environment.
- `manuscript/Scientific_Reports_manuscript_pre_DOI.tex`: manuscript source before insertion of the final Zenodo DOI.
- `DATA_DICTIONARY.md`: provenance and interpretation of deposited artifacts.

## Reproduction in Google Colab

1. Download or clone this release while preserving the folder structure.
2. Open `notebooks/Cellular_Automaton_error_code_v2_reproducible.ipynb` in Google Colab.
3. Select **Runtime → Run all**.
4. If the repository folders are not present in the Colab runtime, upload `data/HerbaceousVegetation_723.tif` when requested.
5. Compare the generated CSV files with the source tables and numerical results retained in the executed notebook.

The publication configuration uses 20 propagation runs (14 training and 6 test), 16 steps per run, five QEC seeds, 20,000 shots per seed, physical error probability 0.006, and code distance 7. Neural robustness uses training seeds 42–46.

## Reproducibility notes

- Every code cell in the deposited executed notebook has a non-null execution count and saved output.
- The GeoTIFF checksum is recorded in `checksums.sha256`.
- CSV files under `results/notebook_output_tables/` were extracted directly from HTML tables embedded in the executed notebook. Their provenance is recorded in `manifest_output_tables.csv`.
- Files listed in `results/expected_exports.txt` are created by the notebook during a clean full execution; they were not independently supplied with the deposit unless also present under `results/`.
- Stochastic CPU/GPU implementations can exhibit small floating-point variation even when seeds are fixed.
